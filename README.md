# Photo Cloud App

Aplikasi photobooth wedding untuk upload, kelola, dan distribusi foto berbasis event.

## Tujuan Project

Project ini dibuat sebagai fondasi aplikasi photo booth wedding yang scalable dan mudah dikembangkan.

## Tech Stack

- Next.js
- TypeScript
- PostgreSQL
- Prisma
- NextAuth
- Supabase Storage
- Docker

## Struktur Folder

- `app/` : routing dan page Next.js
- `components/` : reusable UI components
- `lib/` : helper, util, config
- `prisma/` : schema database
- `docs/` : dokumentasi teknis
- `public/` : aset statis

## Menjalankan Project

1. Install dependency:
   ```bash
   npm install
   ```
